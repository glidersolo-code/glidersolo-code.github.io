The Standard

Florida's crude death rate is higher than Colorado's. Florida is older. The comparison is useless unless adjusted for age.

So the epidemiologist adjusts. Takes Florida's age-specific death rates — death rate for 0-4, 5-9, 10-14, on up through 85+ — and applies them to a standard population. Does the same for Colorado. The standard population provides the weights. The result is a number: age-adjusted deaths per 100,000. The number strips out the demographic confounding. The comparison is now "fair."

The number is hypothetical. It describes no real population's actual death rate. It answers the question: "What would Florida's death rate be if Florida had the age structure of the standard population?" The answer depends on which standard population provides the weights.

The United States used the 1940 standard population for fifty-six years. In 1999, the National Center for Health Statistics switched to the 2000 standard population. The 1940 population was young. The 2000 population is older. The weights shifted. The rates changed.

One consequence: the Black-to-white mortality rate ratio. Using the 1940 standard, approximately 1.61. Using the 2000 standard, approximately 1.42. The same underlying data. The same deaths. The same people. A different ghost population against which the real populations were measured, and the apparent racial disparity shrank by twelve percent.

Nothing changed in the world. The weighting changed. The format — a single age-adjusted rate — does not disclose the standard. The reader sees a number. The number looks like a property of the population it describes. The number is a joint product of two things: the population's actual age-specific mortality and a bureaucratic choice made in 1999 about which hypothetical age structure to use as the reference.

Every age-adjusted rate contains an invisible ghost: the standard population. The ghost determines the weights. The weights determine the comparison. The comparison enters the headline. The headline does not mention the ghost.
