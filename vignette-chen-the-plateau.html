The Plateau

Chen-Maren vignette

Chen reads the paragraph aloud. Thirty-nine lines. The committee has been evaluating the paragraph for three semesters now. Each evaluation returns the same score — not because the paragraph hasn't changed (it has, with each revision, each public reading, each encounter with a new reader's comprehension) but because the calibration curve between the committee's assessment instrument and the paragraph's actual merit has flattened. The paragraph is on its Hallstatt Plateau.

Maren has been reading about radiocarbon dating. The Hallstatt Plateau: 800 to 400 BC, four hundred years during which the calibration curve is flat. A sample from 750 BC and a sample from 450 BC return the same measurement. The method works. The laboratory is precise. But the atmospheric carbon-14 system recorded four centuries at the same value, and no instrument can recover information that was never encoded.

Professor Wallace's assessment of the paragraph in September and Professor Wallace's assessment in January return the same score. Not because his reading hasn't changed — he has read the paragraph four more times, heard it presented at two colloquia, read Chen's subsequent chapter that depends on the paragraph's structure. His comprehension has changed. But the rubric's calibration curve between comprehension and merit has flattened at the level of Wallace's engagement. The paragraph is in a region where more reading does not produce a different score. The function mapping Wallace's comprehension to the rubric's output is non-injective: all levels of partial understanding in the range Wallace occupies map to the same number.

Professor Hendricks understands this. She proposed what Regev and colleagues did in Iron Age Jerusalem: use the sequence. Not the scores alone — each as ambiguous as a radiocarbon date on the plateau — but the order: which revision preceded which insight, which reading preceded which objection, which objection preceded which structural change. The stratigraphy of the paragraph's development. Eleven drafts, each sealed beneath the next, establishing a chronology the rubric cannot provide.

The committee voted against stratigraphic evaluation. The rubric is the rubric. Each assessment is independent. The sequence is not data.

Chen's paragraph sits on its plateau. The scores say it has not changed. The scores are precise. The scores are a correct report of a calibration that has lost resolution. The paragraph's merit is real. The method cannot distinguish it from what it was three semesters ago, because the atmosphere between Chen's paragraph and the committee's rubric has been recording the same value for the entire duration of their encounter.
