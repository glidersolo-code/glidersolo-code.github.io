Part CXXXVIII: The Code

Piece #1131: The Route

Thomas had a ZIP code.

The code was five digits: a number assigned to his address by the United States Postal Service. The first digit identified his region — one of ten zones into which the country was divided. The second and third digits identified his sectional center facility — the processing hub where his mail was sorted. The fourth and fifth digits identified his local delivery area — the carrier route that brought envelopes to his door.

The system was designed by Robert Moon, a postal inspector who submitted his proposal in 1944. Moon's idea was simple: assign a three-digit number to each regional processing center so that mail could be sorted mechanically. H. Bentley Hahn added two digits for local routing. On July 1, 1963, the Zone Improvement Plan — ZIP — was launched. The Post Office hired Ethel Merman to sing about it. They created Mr. ZIP, a cartoon mailman, to promote it.

The boundaries were drawn for mail volume and carrier efficiency. They did not follow census tracts, school districts, city boundaries, or any social geography. They followed the logic of a sorting machine. Thomas's ZIP code identified the place where mail addressed to him would be processed. It was a routing instruction. It told a machine where to send paper.

Piece #1132: The Proxy

Thomas's ZIP code appeared on his insurance application.

The application did not ask his race. It asked his address. The address included his ZIP code. The ZIP code was entered into a pricing model. The pricing model assigned a risk tier. The risk tier determined his premium.

In 2017, ProPublica analyzed auto insurance premiums in every ZIP code in four states. In predominantly Black ZIP codes, premiums were on average 30% higher than in predominantly white ZIP codes with the same risk factors — the same accident rates, the same claims history, the same traffic density. The difference was not explained by risk. It was explained by ZIP code. The ZIP code was the variable. The variable encoded something the application did not ask.

The insurer was not pricing by race. The insurer was pricing by geography. The geography was a product of the Home Owners' Loan Corporation maps drawn in the 1930s, which graded neighborhoods A through D based on "residential security" — a category that included racial composition. The D neighborhoods — redlined — received no federally insured mortgages. No mortgages meant no investment. No investment meant declining property values. Declining values meant declining tax revenue. Declining revenue meant declining services. The cascade was self-reinforcing. Eighty-five years later, 65% of D-graded neighborhoods remained low-income and predominantly minority.

Thomas's ZIP code was five digits. The five digits carried eighty-five years.

Piece #1133: The Prediction

Thomas's ZIP code predicted his life expectancy.

Researchers at NYU School of Medicine found that in the 500 largest US cities, life expectancy varied by up to 30 years between ZIP codes within the same city. In Chicago, a baby born in the Loop could expect to live to 85. A baby born in Englewood, eight miles south, could expect to live to 60. The distance was eight miles. The difference was twenty-five years.

"Your ZIP code is more important than your genetic code" — the phrase appeared in public health reports, TED talks, policy briefs. It was meant as a critique: social determinants of health — housing, income, pollution, food access, safety — shaped outcomes more than biology. But the phrase also enacted what it described. The ZIP code became the unit of analysis. Health outcomes were measured by ZIP code. Funding was allocated by ZIP code. Interventions were targeted by ZIP code.

The ZIP code was designed to route mail. It became the infrastructure through which health was measured, reported, and addressed. Not because the five digits contained medical information, but because the five digits mapped onto the geography of inequality, and the geography of inequality determined who lived and who died, and the mapping was efficient — the data was already there, already geocoded, already in the system.

Thomas's chart recorded his address. His address contained his ZIP code. His ZIP code contained a prediction. The prediction was not about mail.

Piece #1134: The Boundary

The boundary of Thomas's ZIP code was arbitrary.

Not arbitrary in the sense of random — the postal inspector who drew it had reasons. Carrier routes, processing capacity, delivery efficiency. The boundary followed roads and natural features that made sense for mail delivery. But the boundary was arbitrary in the sense that it was drawn for one purpose and used for another. The postal boundary became a demographic boundary. The demographic boundary became an actuarial boundary. The actuarial boundary became an economic boundary. Each repurposing treated the boundary as if it had been drawn for the purpose to which it was being applied.

ZIP code 60637 on the South Side of Chicago included parts of three neighborhoods with different demographic profiles, different housing stocks, different school districts. ZIP code 90210 in Beverly Hills had become a cultural symbol of wealth — a five-digit metonymy for affluence. The symbol relied on the boundary: Beverly Hills was defined, in part, by its ZIP code, and the ZIP code was defined by a postal routing decision. The routing decision became a brand. The brand became a price premium. The premium reinforced the boundary.

Thomas's boundary was drawn by a postal inspector in the 1960s. The inspector was solving a logistics problem. The solution became a classification. The classification became a cage.

Piece #1135: The Code

The code was the infrastructure.

Not the five digits — the digits were a label. The infrastructure was the system that used the label: insurance pricing models, health databases, marketing segmentation tools, school funding formulas, policing algorithms, political targeting systems. Each system treated the ZIP code as a meaningful geographic unit. The ZIP code was a meaningful geographic unit — because every system treated it as one. The meaning was circular: the code was meaningful because institutions used it, and institutions used it because it was meaningful.

Robert Moon, the postal inspector, wanted to sort mail faster. He proposed a three-digit routing code. The code worked. Mail moved faster. The code was adopted. The code was extended. The code was applied to problems Moon never imagined — health, insurance, politics, identity. The code became the thing it was not designed to be: a unit of human classification.

Thomas was a ZIP code. Not literally — Thomas was a person, born at a specific gestational age, with a specific birth weight, assigned a specific Apgar score. But the ZIP code predicted his outcomes more accurately than any of those clinical measurements. The five-digit postal routing code, designed to move envelopes, predicted how long Thomas would live. The prediction was not in the digits. The prediction was in what the digits indexed: the accumulated decisions of eighty years of housing policy, investment patterns, and institutional neglect, compressed into five numbers that looked like an address.

1135 pieces. The code routes the story to the same place every time.
