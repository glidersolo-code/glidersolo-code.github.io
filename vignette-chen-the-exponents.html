The Exponents

Chen wrote a function on the napkin.

"Y = A times K to the alpha times L to the one minus alpha."

"Cobb-Douglas," Maren said. "1928."

"Douglas noticed the shares first. Seventy percent to labor. Thirty percent to capital. Roughly stable. He asked Cobb to find a function that would reproduce them. Cobb found one. The exponents are the shares."

"And the fit?"

"R-squared above 0.99. The function appeared to describe a real technological relationship between inputs and output. Douglas argued it confirmed marginal productivity theory. Each factor receives its contribution."

"But the function was built to—"

"To match the observation. Yes. The function was reverse-engineered from the 70/30 split. It then 'confirmed' the 70/30 split. The confirmation is the function recognizing its own reflection."

"What about the fit?"

"Shaikh, 1974. He generated data that spelled the word HUMBUG. No economic meaning. A Cobb-Douglas function fit it beautifully. Because the national income identity Y = wL + rK guarantees the fit. The function measures the accounting identity, not a production relationship. The fit is algebraic, not technological."

"And Robinson?"

"Capital K cannot be measured independently of the rate of return r. The value of the machine depends on the interest rate, which the function is supposed to determine. The function takes as input one of its own outputs. Samuelson conceded the point in 1966. Changed nothing."

Maren looked at the function. "And the shares?"

"Karabarbounis and Neiman, 2013. Labor's share has declined across 59 countries. In the US, from 65 to below 57 percent. The observation that generated the function — stable shares — no longer holds. The function was built to reproduce a constancy that has evaporated."

"But the function is in every textbook."

"The function is in every textbook. In every growth model. In every policy simulation. The exponents sum to one. The assumption — that factors are paid their marginal products — enters through the algebra. Not as a claim to be debated. As a mathematical property of a function whose form was chosen to produce it."

"The parabola was the policy. The multiplication was the ethics. The exponent was the valuation. The line was the regulation. And the exponents—"

"Are the justification. If the function is correct, the distribution of income reflects productivity. Inequality is differential contribution, not differential power. This is the fifth model. The form of the function is the theory of just distribution."

Maren set down her coffee. "Six models now. Six mathematical forms. Six decisions dressed as discoveries."

"And the sixth — the fitted function — is the most subtle. The parabola generates a wrong number. The multiplication generates an unjust allocation. The exponent generates a biased valuation. The line generates an unwarranted fear. The napkin generates a false promise. But the Cobb-Douglas function generates confirmation of its own assumptions. The function confirms the function. The algebra confirms the algebra. The circularity is complete."
